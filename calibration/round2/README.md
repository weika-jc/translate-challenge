# 第二轮 Judge 校准

本轮从当前带参考译文的公开语料和九个历史模型结果中分层抽取 100 条候选，排除了第一轮已经标注的 50 条原文。

样本构成：

- 70 条 `dev`、30 条 `holdout`；
- 50 条正常随机样本、30 条旧分数较低的疑似错误样本、20 条短句/相近语言/特殊内容边界样本；
- 旧调用人为添加的单层外引号已确定性移除；原文本身带外引号时不做修改；
- `human-label-map.csv` 保存匿名候选对应的模型、旧分数和抽样层级，人工标注期间不要查看。
- `reference-exclusions.json` 保存已确认原文与参考译文不匹配的样本；`run-human` 和基于参考译文构造的对照会自动排除这些样本，但原始人工标注保持不变。

第一步只填写 `human-labels.csv` 中 `split=dev` 的 70 行，holdout 必须保持空白。填写规则：

- `acceptable=yes`：`worst_severity` 为 `none` 或 `minor`；
- `acceptable=no`：`worst_severity` 为 `major` 或 `critical`；
- `primary_category`：有错误时填写 `accuracy`、`fluency`、`tone`、`terminology` 或 `preservation`，无错误时留空；
- `note`：可选；原文缺少上下文、无法唯一判断时写明 `ambiguous`，这类样本不进入核心验收。

dev 已完成标注：70 条中有 57 条可接受、10 条 major、3 条 critical，另有 2 条 `ambiguous`。排除 ambiguous 后，宽松基线在 68 条核心样本上的 Judge 可接受性一致率为 92.65%，不可接受召回率为 76.92%，平衡准确率为 86.64%。一次只修改通用 rubric 的实验没有改善召回且增加误杀，已回退，不采用该版本。

宽松基线重跑 97 组自动损坏对照后，Judge 单独正确 96 组（98.97%），结合硬规则后正确 97 组（100%）。核心验收采用临时宽松门槛：总体一致率不低于 85%、平衡准确率不低于 80%、不可接受召回率不低于 75%。minor 不设硬门槛。

dev review 后将数字形式不一致从 hard fail 降为 `preservation/minor`：例如 `第３位 → Tercer lugar` 允许通过，记录 `number_not_exact` 并扣 3 分。4 组真正数字替换对照全部通过，其他硬规则不变。按新规则离线修正后，dev 的系统可接受性一致率和平衡准确率分别为 92.65% 和 86.64%。

人工复核确认 5 条 dev 的参考译文与原文不符或混入额外上下文，已加入显式排除清单。它们仍保留在标注表中用于数据质量追踪，但不再参与任何使用参考译文的 Prompt 调整、指标验收或自动对照构造。无需重跑 Judge，使用现有输出并应用当前数字软规则重算后，共评估 63 条核心样本、其中 12 条不可接受：总体一致率 93.65%，不可接受召回率 75.0%，平衡准确率 86.52%，仍满足临时宽松门槛。

holdout review 前进一步明确了“原文照抄”规则：候选与参考译文完全一致时允许通过；没有参考确认的短文本同形只记录 `source_copy_suspected`，按 `accuracy/minor` 扣 3 分；较长文本跨语言整句照抄仍为 `source_copied` 硬失败。三条候选与参考完全一致的 holdout 样本均按正确译文得到 100 分。

30 条 holdout 已完成人工标注，其中 2 条备注明确指出参考译文与原文不对应，按预先确定的数据质量规则加入排除清单。冻结配置对其余 28 条只进行了一次有效评测：系统可接受性一致率 96.43%，不可接受召回率 75.0%（3/4），平衡准确率 87.5%，三项均达到临时门槛。唯一影响可接受性判断的漏检是候选中残留未翻译的挪威语片段 `Den?`；另有 2 条 minor 语气偏正式未被 Judge 报告，但不影响可接受性。Judge 平均延迟 1529 ms、中位 1304 ms、P95 3156 ms，平均输入约 1317 token、平均输出约 11 token。当前 Prompt 和判定协议在补充真实业务数据前冻结。
